\textbf{Question 2.1}

% \[
% 	\sum_{n=2}^{\infty} \frac{1}{n(\ln n)}
% \]

To know if this series converges or diverges, I will use the integral test. For this, I have to rewrite the series in function form (so it's easier for me to visualise) and then I convert it to integral form:

\[
f(x) = \frac{1}{x(\ln x)} \rightarrow \int_{2}^{\infty} \frac{1}{x(\ln x)} dx
\]

Then we do substituion:

\begin{itemize}
	\item $u$ = $\ln x$
	\item $du$ = $\frac{1}{x} dx$
	\item $dx$ = $x \cdot du$
\end{itemize}

\[
\int_{2}^{\infty} \frac{1}{x(\ln x)} dx = \frac{1}{x \cdot u} \cdot x \hspace{0.1cm} du = \frac{1}{u} du 
\]

initially the limits were from 2 to $\infty$, but now we need to change them to $u$ values:
\begin{itemize}
	\item when $x = 2$, $u = \ln 2$
	\item when $x \rightarrow \infty$, $u \rightarrow \infty$
\end{itemize}

So now the integral looks like this:
\[
\int_{\ln 2}^{\infty} \frac{1}{u} du
\]

And now we can solve the integral using the standard formula $\int \frac{1}{u} du = \ln|u| + C$:

\[
\int_{\ln 2}^{\infty} \frac{1}{u} du = \ln|u| \Big|_{\ln 2}^{\infty} = \lim_{t \to \infty} [\ln(\ln t) - \ln(\ln 2)] = \infty - \ln(\ln 2) = \infty
\]

Since the result of the integral is $\infty$ (the integral diverges), that means the series also diverges.
