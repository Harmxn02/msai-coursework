\subsection*{exercise b}

To prove this, we need to check the three properties of an inner product, according to the Savov book:
\begin{itemize}
	\item \textbf{Symmetric}: $\langle u, v \rangle = \langle v, u \rangle$
	\item \textbf{Linear}: $\langle u, \alpha v_1 + \beta v_2 \rangle = \alpha \langle u, v_1 \rangle + \beta \langle u, v_2 \rangle$
	\item \textbf{Positive semidefinite}: $\langle u, u \rangle \geq 0$ for all $u \in V$ with $\langle u, u \rangle = 0$ if and only if $u = 0$
\end{itemize}

\underline{Symmetric}

To prove that $\langle f, g \rangle = \langle g, f \rangle$, we need to show that:

\[
\int_{-1}^{1} f(t) g(t) dt = \int_{-1}^{1} g(t) f(t) dt
\]

The only difference here is the order of multiplication of $f(t)$ and $g(t)$, but since multiplication is always symmetric (e.g. $3 \times 4$ gets the same result as $4 \times 3$), the integrals are equal, so the inner product is symmetric.


\underline{Linear}

An inner product is linear if:
\[
\langle \alpha f_1 + \beta f_2, g \rangle = \alpha \langle f_1, g \rangle + \beta \langle f_2, g \rangle
\]

So I need to show that:

\[
\langle \alpha f_1 + \beta f_2, g \rangle = \int_{-1}^{1} {(\alpha f_1(t) + \beta f_2(t))} g(t) dt
\]

First I can distribute $g(t)$ inside the integral:

\[
= \int_{-1}^{1} \alpha f_1(t) g(t) + \beta f_2(t) g(t) dt
\]

Then I can split the integral into two integrals:
\[
= \alpha \int_{-1}^{1} f_1(t) g(t) dt + \beta \int_{-1}^{1} f_2(t) g(t) dt
\]

\[
= \alpha \langle f_1, g \rangle + \beta \langle f_2, g \rangle
\]

So the inner product is linear.



\underline{Positive semidefinite}

An inner product is positive semidefinite if 
\[
\langle f, f \rangle \geq 0 \quad and \quad \langle f, f \rangle = 0 \iff f = 0
\]

So instead of $g$ I put $f$ in the inner product:

\[
\langle f, f \rangle = \int_{-1}^{1} f(t) f(t) dt = \int_{-1}^{1} {(f(t))}^2 dt
\]

${(f(t))}^2$ is always non-negative so the integral of ${(f(t))}^2$ over any interval is always $\geq 0$.

And if $\langle f, f \rangle = 0$, then the only way this can happen is when $f(t) = 0 \quad \forall t$ 


\[
\boxed{\text{All 3 properties hold, so this is indeed an inner product}}
\]

\[
A^{-1}A\vec{x} = A^{-1}\vec{b} \implies \vec{x} = A^{-1}\vec{b}
\]

So there exists a solution for each $\vec{b} \in {\mathbb{R}}^n$

\underline{Uniqueness of solution}

If I assume there are two solutions $\vec{x_1}$ and $\vec{x_2}$ so that:

\[
A\vec{x_1} = \vec{b} \quad and \quad A\vec{x_2} = \vec{b}
\]

Then that would mean that:

\[
A (\vec{x_1} - \vec{x_2}) = \vec{0}
\]

From (4) we know that the only solution to this equation is the trivial solution $\vec{x_1} - \vec{x_2} = \vec{0}$, so $\vec{x_1} = \vec{x_2}$

	\item (5.2) True, because the columns of $A$ span ${\mathbb{R}}^n$ when $A$ is invertible (see (1))

\[
{A}^T = \begin{pmatrix}
	1 & 0 & 0 \\
	2 & 1 & 0 \\
	0 & 3 & 5
\end{pmatrix}
\]

The determinant of ${A}^T$ is also 5 ($1 \times 1 \times 5 = 5$), and a square matrix is invertible when the determinant is nonzero, so ${A}^T$ is invertible.
