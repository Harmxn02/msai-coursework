# Master of Science in Artificial Intelligence

This repository contains notes made with LaTeX during the pursuit of my Master of Science in Artificial Intelligence @ [**Open Universiteit**](https://ou.nl/).

## Structure

- Every folder corresponds to a course.
- Inside each folder, you'll find subfolders for each chapter.

### Commit messages

- I use the `(partial)` prefix if the notes are still in progress.
- I use the `(template)` prefix if I have added the LaTeX source files, but have not started making notes yet.
- I use the `(fix)` prefix if I made corrections
